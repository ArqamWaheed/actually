# Actually

How long will it *actually* take? A time-blindness helper built for a friend with ADHD.

Brain-dump your day → a small open model fine-tuned on Tinker splits it into tasks → TabPFN, reading *your own* history of guessed vs real durations, tells you how long each one really takes you, and what fits in the time you have.

Runs entirely on one box: fine-tuned Qwen3.5-4B (GGUF) + local TabPFN + FastAPI + SQLite.
